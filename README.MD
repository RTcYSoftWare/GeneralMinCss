# General Css Package

Bu proje, CSS projelerinde tekrar tekrar kullanılabilecek sabitler, yardımcı sınıflar (helpers) ve utility fonksiyonlarını barındıran bağımsız bir **CGeneral Css Package** dosyasıdır. Css kullandığınız ve geliştirdiğiniz projelerde bu yapıyı her defasında sıfırdan oluşturmak yerine, `CDN linki` kullanarak dahil edip kolayca kullanabilirsiniz.

---

## 🔄 General CSS'i CDN Olarak Projeye Ekleme :

General CSS'i bir projeye CDN linki olarak ekleyerek, kodu doğrudan çözüm içerisine çekebilir ve projelerinizde kullanabilirsiniz.

Aşağıdaki linki html sayfanıza yapıştırdığınızda General CSS'i kullanabilirsiniz.

```
https://cdn.jsdelivr.net/gh/rtcysoftware/GeneralMinCss@latest/general.min.css
```

```
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/rtcysoftware/GeneralMinCss@latest/general.min.css">
```
